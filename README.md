# 📂 10 Basic Tasks & Algorithms in C++

Коллекция базовых и прикладных задач по программированию, реализованных на языке C++ в ходе изучения университетской программы.

## 📌 Описание проекта
Репозиторий содержит серию лабораторных и практических заданий, направленных на отработку фундаментальных навыков программирования: работа с файловыми потоками, обработка массивов и матриц, реализация алгоритмов сортировки и условной логики.

## 🛠️ Стек технологий
* **Язык программирования:** C++ (файловый ввод/вывод, стандартные алгоритмы, функции, структуры данных)

## 🚀 Что входит в проект
* Автоматизированное чтение, фильтрация и структурирование данных из текстовых файлов.
* Разработка условных алгоритмов для численной обработки данных.
* Реализация классических алгоритмов сортировки и поиска.
